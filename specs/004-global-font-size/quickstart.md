# Validation guide

1. Run documented prerequisites and existing repository/product checks.
2. Run `npm run qualify` on Windows using the small fixture.
3. Native acceptance selects90/80/100, compares computed fonts and stable geometry, restarts at80 and verifies default restoration. Rust checks legacy bytes/unknown choices and invalid-value handling.
4. Use the normal rebuilt `.local/bin/local-media-gallery.exe`; open Settings and choose Global font size.

No remote, release or bulk-media benchmark is part of this enhancement.
