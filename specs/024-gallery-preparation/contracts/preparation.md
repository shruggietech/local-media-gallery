# Guided preparation contract

Native commands expose preview(selection, sessionId, expectedRevision), start(sessionId, previewId), status(sessionId, jobId), cancel(sessionId, jobId). Window authority and native captured roots authorize operations; frontend paths do not.

Presentation captures only known effective settings and writes the compatible portable format accepted by elected published recipients. Unknown document fields survive. A failed persistence warning is an action failure. Thumbnails use the existing portable cache worker; cleanup remains separate.

Recipients resolve only from canonical published native release.json with immutable candidate digest, publication binding and artifact URL/byte/digest validation. Complete ZIP/tar.gz payloads are retained under platform folders; no archive links, traversal, duplicate/case-colliding paths or special files are admitted. Output receipts contain relative inventories and release identities, never sender paths/history. Root launch entrypoints resolve the moved gallery without a manifest.

Preview shows exact output paths, release/artifact identity, download bytes, extracted bytes and root-entrypoint duplication. Existing matching receipts permit reuse only after full inventory revalidation. Conflicts are preserved and reported per recipient; other choices may complete.

The finite prepare CLI retains bare-preview behavior and existing thumbnail flags; guided native UI orchestrates independent choices. Every job reports complete/partial/canceled results and progress. Gallery selection changes cancel work; stale-session jobs cannot commit.
