4. **Brand**: Reuse exact delivered48/256/512 PNG bytes under hicolor, recording source-to-destination hashes; no generated logo or kit edits. Full desktop entry uses exact application name, one directory argument, no invented marketing text/default associations/WMClass.

6. **Shell boundary**: Maintainer scripts are dpkg protocol entry points, not generic operator tools. The Ubuntu24.04 election defines support evidence, not an OS-label eligibility ban. Recipient preflight checks actual target architecture and GNU loader/library compatibility; another host is not denied solely by its distribution/version label. Other combinations remain unqualified.

Canonical candidate installation/repeat uses apt install --reinstall ./FULL.deb. Plain APT install can return an already-installed no-op for an equal Debian version without running maintainer verification; explicit reinstall exercises the exact owned-candidate guards. Different same-version candidate and changed-owned-file negatives exercise actual dpkg/apt fallback paths.

Batch dpkg-query ownership/diversion lookups across all literal authority paths instead of reparsing the complete package database once per notice file. Preserve individual physical path, byte and mode checks. Private package path metadata rejects ownership-query glob metacharacters; this does not constrain gallery/media paths.

The reused proof TAR extractor checked names/types/sizes but allowed raw mode drift that the data filter could normalize away. A real777/setuid fixture reproduced this gap. Compare raw member modes to the declared inventory before extraction, preserving exact executable-mode claims across all proof users.
