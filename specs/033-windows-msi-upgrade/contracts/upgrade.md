# Ordinary Windows upgrade contract

The ordinary entrypoint is the single downloaded Full MSI opened with full native UI. Diagnostic invocation may add native verbose logging and no-restart, but must not silently supply scope, location or integration choices. Machine predecessor context/location/choices must be inherited and visible. A user follows the ordinary license/options/install/finish journey.

The published-pair baseline uses exact canonical inputs. Retain the reported 267 text and original MSI log, source/host/token/directory observations, before/after native state and attributable dialog evidence. Captures must remain bound to product-owned MSI windows; multiple windows cannot justify an unrestricted desktop screenshot.

Candidate acceptance requires terminal native success, one matching installed product/package, installed payload verification and ordinary launch, unchanged retained byte inventories, and absence of orphaned predecessor registration. Cancellation and invalid ownership/source retain valid state and diagnostics. No owner workaround, manual uninstall, registry editing or published-input mutation is an accepted fix.

The regular package receipt must explicitly elect ordinary v0.2.0 replacement and distinguish full UI from quiet and advanced recovery. Existing native/source/clock/byte/guard checks remain mandatory. Authored files use UTF-8 without BOM and LF.
