Native still output is PNG fitting320x320, no crop/enlargement, preserved alpha, applied EXIF orientation (all eight transforms), first still/frame for animated input. Product neither searches PATH nor downloads/bundles it. A local hash binds chosen bytes, not publisher authenticity or unknown dynamic dependency bytes. Read-only source authority is inherited as regular-file stdin, using -nostdin -protocol_whitelist fd -i fd:, with first non-attached video frame, no audio/subtitle/data, PNG stdout, one decoder/filter thread. Decision: machine-local initial choice and explicit portable child .local-media-gallery-thumbnails-v1. Dedicated product/kind/version ownership document, no-follow directories/files, regular bounded entry records. Single immutable envelope includes base64 PNG, outputSHA/dimensions and source/provider/policy facts, capped6MiB. Exact source-key/content-policy-key names with16 no-clobber slots accommodate provider changes, invalid records and concurrent collisions; matching valid entries are reused. An occupied unrecognized slot is never overwritten. Exhaustion reports collision and explicit owned cleanup guidance, without restricting ordinary browsing. Preview names selected destinations/slots and storage upper bound; source/destination/slot changes require another preview.

Stage/validate first; use no-clobber hard-link publication when available. On filesystems without hard links, reserve the exact destination with create_new and finish a validated single JSON envelope; readers accept only a complete bounded record with valid output. Partial reservations are misses and never replace prior valid entries. This is recoverable publication, not universal atomic rename. Cooperative writer lock uses explicit operation-owned unlock. Cleanup is explicit, bounded and per-file, deleting only validated owned records/staging and retaining unrecognized/corrupt/future content. No recursive deletion, mutable index or automatic eviction. Alternatives: mutable compare/rename risks unrelated final-boundary overwrite; hard-link-only would silently exclude portable filesystems. Pre/post source checks do not promise an atomic filesystem snapshot against arbitrary concurrent in-place editing.

## Diagnostics

Decision: typed allowlisted DiagnosticStore shared by Engine and host, not clones of OperationResult, settings, snapshots, raw errors or stderr. Retain256records and256KiB exact serialized record bytes, decimal dropped counts, until process exit; no ordinary disk logger. Stable internal code table supplies category/message/recovery. Context: product/version/edition/OS/arch/target/runtime, opaque operation/session/item identities, status/boundary and nullable exact counts. Exclude private paths/names/URLs, credentials, sidecars, recents and raw helper messages. Record discovery terminal transition once, typed state failures before warning flattening, core media errors before404mapping, and bounded current-item renderer decode/playback observations. Avoid snapshot-triggered diagnostic flooding.

UI exposes described report inspection and explicit native Save dialog export. CLI diagnostics reports only this invocation; requested --diagnostics adds a report to the existing single OperationResult envelope. Do not invent cross-process log access or disk persistence. Recovery preserves invalid/future user state and previous committed caches. [Ctrl-C3.5.2](https://docs.rs/ctrlc/3.5.2/ctrlc/) supplies requested CLI cancellation; Windows attaches only an existing parent console without allocating a window, Unix termination signals request the same cancellation token. Unknown helper lifetime remains explicit.
