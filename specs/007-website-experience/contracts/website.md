# S007 website contracts

Canonical Markdown and JSON remain inert publication inputs. Existing route, raw hash, captured-reference, search/version and verified-download contracts remain enforced. Generated markup may add presentation controls but may not alter authored text or historical source bytes.

The reading shell is Fumadocs inside the governed AppFrame scroll owner. Heading IDs are deterministic, duplicate-safe and shared by the generated TOC. Native anchors retain history. Motion obeys reduced-motion preferences. Navigation controls expose names, expanded state and keyboard dismissal.

Code is highlighted by Shiki during build, copied exactly with observable failure feedback, and readable without JavaScript. Diagrams are strict build-rendered SVG with no script, event handlers, foreignObject or external references; deterministic unique IDs; accessible title/description; governed fonts; visible source; and local overflow at native legible dimensions.

Metadata and assets use canonical retained routes and governed identity bytes. No fabricated release links, social handles, ratings, downloads or field performance claims. A missing source, malformed diagram, unsafe URI, unresolved local link or unverified release record fails the build.

Acceptance evidence must bind the checked artifact to its source and final deployed revision. The owner performs merge after exact-head CI and bounded external reviews.
