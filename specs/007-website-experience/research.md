# S007 research decisions

Research on 2026-10-23 inspected the actual fragcap, shruggie-brand and go-schedule site implementations, their custom styles, brand generators, documentation navigation and build configurations. This is implementation evidence, not a directive to copy private content.

- Next.js remains the existing static-export runtime. Fumadocs16.17.8 UI/Core support Next16/React19 and manual page trees with ordinary React children, so executable MDX is unnecessary. Use docs-only RootProvider with built-in search/theme controls disabled and retain version-scoped search. [Fumadocs layout](https://fumadocs.dev/docs/ui/layouts/docs), [Next static export](https://nextjs.org/docs/app/guides/static-exports).
- Shiki4.5.0 supports build-time HTML and CSS-variable theme colors. One initialized highlighter preserves the synchronous Markdown adapter interface. Do not nest generated pre elements or execute unknown fences. [Shiki themes](https://shiki.style/guide/theme-colors), [Shiki highlighter](https://shiki.style/guide/bundles).
- A local Mermaid prototype rendered four diagrams in both themes in0.667 seconds after readiness. Root and flowchart htmlLabels must both be false. Inline SVG inherits governed fonts; external SVG images cannot reliably do so. Strict rendering, unique IDs and explicit diagram descriptions are mandatory. [Mermaid configuration](https://mermaid.js.org/config/schema-docs/config.html), [Mermaid accessibility](https://mermaid.js.org/config/accessibility.html).
- Brand kit supplies the exact approved headline, metadata description, font faces, light/dark tokens and icon/social bytes. Its AppFrame owns a nested scroll container. Fumadocs sticky sidebar/TOC can fit that contract with consumer-owned height measurement; switching to window scrolling would break it.
- Native scrolling, reduced-motion preferences and link focus must remain usable. Colorized wrapped underlines add a non-color cue; animations cannot introduce layout shifts. [WCAG2.2](https://www.w3.org/TR/WCAG22/), [MDN reduced motion](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion).
- Route metadata, sitemap and canonical URLs follow actual retained versions. Duplicate aliases use canonical links; noindex is reserved for error pages. [Google canonical guidance](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls), [Next metadata](https://nextjs.org/docs/app/api-reference/functions/generate-metadata).
- Performance uses cold laboratory samples with fixed throttling and explicit decoded/gzip sizes. Field Core Web Vitals are a separate future observation. [Web Vitals](https://web.dev/articles/vitals), [Playwright accessibility testing](https://playwright.dev/docs/accessibility-testing).

The measured baseline and preimplementation budgets are recorded in plan.md. No remaining technical clarification blocks implementation.

## Actual reference implementations and adaptations

The inspected go-schedule implementation uses Next16.4.2, React19.3.1, Fumadocs16.17.7, MDX15.4.8, next-themes0.4.6 and Tailwind4.3.3. Its custom hero/workflow composition informed the task-oriented landing arrangement. shruggie-brand uses Fumadocs16.15.11 with custom sidebar, page tree, typography, theme, underlines and metadata. fragcap supplied useful source examples for Mermaid accessibility and computed syntax-contrast checks. The current registry pins were checked separately; selecting Fumadocs16.17.8 does not imply the sibling source already uses it.

Local adaptation preserves a safe Markdown adapter rather than adopting executable MDX, uses a measured AppFrame scroll height, supplies its own native active TOC to honor reduced motion, and adds modal keyboard behavior to the framework sidebar. Scoped public layout slots are used. The pinned package’s docs/base CSS and only the needed layout/UI class sources avoid loading unused notebook, flux, search-dialog and media styles; package upgrades must requalify this scoped style integration.
