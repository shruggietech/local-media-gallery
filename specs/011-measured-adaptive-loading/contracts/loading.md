# Loading and Measurement Contracts

## User choice

loadingMode: automatic (default), conservative or standard. Existing settings destinations and precedence apply. Changing it calls the ordinary settings mutation without resetting page or viewer. Stored mode has no effective concurrency, frame or latency samples.

## Policy boundary

Pure controller accepts monotonic bounded observations and current outstanding work. Reports finite effective preparation allowance, prefetch interest and reason. Automatic pressure/recovery thresholds and sample-window limits are recorded after baseline measurement. Manual policies remain fixed. Visible waiting work outranks prefetch; a lower cap never invents completion/cancellation of active work.

## Native resources

Existing root/session/item authority remains mandatory. Discovery, sidecar and transport limits remain independent finite classes. The native-test-only s011_resource_snapshot action on the existing gated test control contains actual permit counts/caps, requires the main window and performs no filesystem work. The normal artifact excludes this action. No arbitrary path input or new root access.

## Evidence boundary

The same external harness runs baseline and final binaries. Report command-to-render durations separately from in-renderer measurements, callback-gap observations separately from frame presentation, private bytes separately from working sets, sampled/endpoint memory separately from guaranteed peaks, and process-cold separately from OS-cache-cold. Packages and thumbnail generation remain unavailable rather than inferred from a debug binary.

## Lifetime

Retired queue/session observations cannot tune a replacement. Focused media identity remains unchanged across preference, metadata and sidecar Refresh changes. Gallery sources/probes are zero while focused or hidden. Explicit Refresh is still required for directory changes.
