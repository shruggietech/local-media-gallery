2. Run npm run check and npm test. Release cases cover strict identities, path/foreign collisions, snapshot capture, stale gate binding, observed publication and repeated recovery using a controlled HTTP service.

4. Run hosted qualification for existing eight scopes and the dependent release-validation campaign. Native ordinary packages, supporting Linux descriptor and exact source/qualification records feed assembly. No replacement/negative/runtime-proof payload becomes a primary release artifact.
5. Independently read back retained archive digests, native/package evidence, documentation gates, release fixture outcomes and final source/head identity. Preserve preparation/qualification/combined times and660/900/15-second rules.
