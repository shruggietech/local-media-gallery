# S010 Validation Guide

1. Prepare existing local prerequisites with npm run prepare:local using the verified hidden Windows launcher. Record readiness before qualification.
2. Run npm run check, npm test, npm run check:app, npm run check:docs, npm run check:site and npm run test:site. Run Cargo core/shell tests and actual native WebView groups through npm run qualify.
3. In the generated small fixture, open focused Information. Inspect exact-name sidecars, a scalar, a legacy-shaped index and nested duplicate keys. Compare huge numeric tokens, false/zero/null/empty and active-looking text against immutable source bytes.
4. Choose nested summary fields at each existing destination, restart/relocate and exercise explicit empty/inheritance, invalid/future state and failed writes. Missing fields remain visibly missing.
5. Play the synthetic video, expand information and nested fields, save summaries and change only its sidecar before Refresh. Assert same media node and continuing playback.
6. Hold a prepared read across Refresh/navigation/root change; release it and assert obsolete results never replace current values. Exercise file/root/link replacement, malformed/encoding/budget failures and repaired explicit retry without media loss.
7. Check keyboard focus, global text scale, narrow windows, lazy sibling paging and no card-side inspection. Compare all source/media/brand hashes and retain terminal preparation/qualification/combined timings.
8. Push/open the official PR with closing references to #13/#14 after qualification. Inspect CI and individual reviews, fix findings within at most two rounds, and notify the owner for final review and squash merge.
