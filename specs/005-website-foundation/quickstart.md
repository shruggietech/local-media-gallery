# Quickstart: Website validation

1. Install locked npm dependencies and prepare the existing native/brand prerequisites with npm run prepare:local.
2. Run npm run build:site, npm run check:site and npm run test:site. The static export is apps/site/out; serve it with any ordinary static server.
3. Open landing, all fifteen baseline chapters, search, changelog and schema references; inspect narrow keyboard navigation and diagram source fallbacks.
4. Run npm run check, npm test, npm run check:docs, npm run check:app and npm run qualify for the elected local Windows evidence.
5. Inspect hosted CI on the exact PR head, downloaded evidence/artifact hashes and required-check policy before owner review. Product packages and live domain deployment remain separate issues.
