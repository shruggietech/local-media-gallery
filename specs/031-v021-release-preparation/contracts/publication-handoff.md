# Publication handoff contract

S031 ends with an official open PR, complete final-head qualification, retained exact input/product/documentation identities, all received findings resolved within at most two hosted Codex rounds, and owner notification. It does not merge, tag, publish or promote.

A later authorized execution must select a successful trusted-main Qualification run, version 0.2.1 and predecessor 0.2.0. It must retain the existing manual-main/current-renderer and verified predecessor checks, candidate/publication documentation gates, exact accepted assets without rebuild, upload recovery authority and independent public selection verification.

Canonical input artifacts retain their existing selection and bounds. When the accepted Windows gate carries a cohort, its complete receipt must first match the candidate's recorded Windows scope hash. Supporting references then elect exact experience/lifecycle artifacts by immutable IDs/digests/size and the same run/revision/source/attempt/common clock. Legacy non-cohort gates require no invented support. Every selected original archive remains retained; changed, expired, foreign, duplicate, missing or oversized evidence fails before publication.

Post-publication readback must verify canonical release.json, all selected product/source assets and hashes, public documentation/latest/download selection and actual prepared-recipient acquisition. Actual availability must never be inferred from source-version text alone. Known v0.1.0 custom-location removal remains separately tracked; client trust/elevation prompts are not claimed observed by hosted Server qualification.

Release highlights remain concise and the existing publisher appends the master changelog link. Suggested highlights cover the self-contained Windows MSI wizard and private settings/storage/maintenance fixes; they do not announce navigation redesign or a legacy-recovery fix.
