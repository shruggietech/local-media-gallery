# Data model: S037

- Installed identity: version, product/package/component GUIDs, scope, native states, registered spelling and pinned physical directory/file identity.
- Matrix case: actual path/UTF-16 length, drive, structure/dot/repetition/character controls, MSI digest, engine identity, before/after lookup facts and original uninstall outcome.
- Recovery inputs: authenticated canonical MSI, descriptor/payload hashes, selected scope, journal, lease and native worker identity.
- Repair alias: an actual filesystem short-name spelling of the same pinned directory, if evidence elects it; no link or unrelated destination gains authority.
- Outcome: observed, verified, admitted, mutating, incomplete, complete/restored/refused. Completion requires native terminal authority and registration/payload/data readback.
