# Data model: S037

- Installed identity: version, product/package/component GUIDs, scope, native states, registered spelling and pinned physical destination.
- Matrix case: actual path/UTF-16 length, drive, structure/character controls, MSI digest, engine identity, native observations and original uninstall outcome.
- Legacy patch: target original version/product/package, compiled original payload manifest, guard digest, exhaustive native-table delta, patch code, generation and final MSP bytes/hash. Full payload inventories authenticate the retained artifact.
- Recovery inputs: immutable canonical MSI, descriptor/payload hashes, selected scope, journal binding, lease and native worker identity.
- Native step: sealed selected-patch record, already-applied observation, exact job/client identity, native terminal code, unique native log and completed receipt bound to the outer immutable identity.
- Outcome: observed, verified, admitted, mutating, incomplete, complete/restored/refused. Completion requires native terminal authority and registration/payload/integration/data readback. A coordinator timeout does not terminate its worker.

The rejected short-name alias experiment is historical research, not a current recovery entity.
