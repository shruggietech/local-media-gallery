## Migration impact

No approved identity redesign is included. Brand version `1.0.0` remains distinct from package `localmedia-gallery-brand-1.0.0-bb3.1.0`.

| Surface | Classification | Guidance |
| --- | --- | --- |
| Identity | unaffected | Existing approved masters and proof bytes remain unchanged. Local Media Gallery 1.0.0 is a new, separately approved Jade identity with photo and video cutouts. |
| Palette | unaffected | Existing palette values and WCAG 2.1 AA rules remain unchanged. |
| Typography | unaffected | Approved local font families, faces, and licenses remain unchanged. |
| Platform Assets | optional | Regenerate to adopt optional source-owned horizontal wordmark rows, centered-group slogan-only social images, and corrected long-name/compound type specimens. Existing default logo layouts and approved social images remain unchanged. |
| Web React | unaffected | Web and React adapter APIs and interface token behavior remain unchanged. |
| Egui | unaffected | The egui adapter API and output semantics remain unchanged. |
| Wordpress | unaffected | WordPress adapter 1.0.0 retains its public contract and supports the compatible Brand Canon 2.1.0 tuple. |
| Documentation | required | Publish Local Media Gallery guidelines, approved exact messages, registries and downloads through standard generated routes. Brand Canon 2.1.0 adds optional lockup layout and social composition fields; earlier conforming inputs remain supported. |
| Recovery | required | Repinning BrandBuilder 3.1.0 requires its exact new package IDs and checksums. The verified site hosts thirteen brands; ten owned archives join the skill and portable distribution, while three client kits remain hosted candidates. Previously published packages remain immutable recovery inputs. |

`required` applies to existing use of that surface, `optional` is an available capability, and `unaffected` requires no migration.
