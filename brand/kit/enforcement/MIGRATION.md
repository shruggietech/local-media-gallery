## Migration impact

No approved identity redesign is included. Brand version `1.0.0` remains distinct from package `localmedia-gallery-brand-1.0.0-bb3.1.1`.

| Surface | Classification | Guidance |
| --- | --- | --- |
| Identity | unaffected | Approved logo geometry and source masters remain unchanged. Seven edited brands receive patch package versions for messaging; identity remains governed by their existing continuity records. |
| Palette | unaffected | Existing palette values and WCAG 2.1 AA rules remain unchanged. |
| Typography | unaffected | Approved local font families, faces, and licenses remain unchanged. |
| Platform Assets | optional | Regenerate and repin to adopt exact approved messaging in generated packages. Approved logo geometry, platform icon layouts and social-image compositions remain unchanged. |
| Web React | unaffected | Web and React adapter APIs and interface token behavior remain unchanged. |
| Egui | unaffected | The egui adapter API and output semantics remain unchanged. |
| Wordpress | optional | Regenerate WordPress starters to adopt exact approved site descriptions and omit the hero description when the canonical site-metadata role is absent or unresolved. WordPress adapter 1.0.0 retains its public API. |
| Documentation | required | Publish seven brands' exact approved message decisions, corrected portfolio heading and complete card-title layout, and all 68 labeled References entries. Brand Canon 2.1.0 and existing adapter APIs remain unchanged. |
| Recovery | required | Repinning BrandBuilder 3.1.1 requires exact new package IDs and checksums. The site hosts thirteen verified brands; ten owned archives join the skill and portable distribution, while three client kits remain hosted candidates. Previously published packages remain immutable recovery inputs. |

`required` applies to existing use of that surface, `optional` is an available capability, and `unaffected` requires no migration.
