# Glossary

Definitions apply to this specification. Product-specific terms are defined locally; general technical terms include primary learning references. A local usage link identifies the chapter that owns the relevant behavior.

| Term | Definition | Primary reference and local usage |
| --- | --- | --- |
| Application-owned contract | A documented structure/operation produced or controlled by the gallery, such as settings or native messages; distinct from arbitrary external sidecars | [Local contract boundary](interfaces-and-contracts.md#contract-boundaries) |
| AppData | Windows user application-data locations; the installed product's settings belong beneath the appropriate AppData scope | [Windows known folders](https://learn.microsoft.com/en-us/windows/win32/shell/knownfolderid), [installed locations](configuration-and-state.md#installed-locations) |
| Application bundle | A platform package presenting an application with its executable/resources as a unit; its internal executable directory need not be the gallery root | [Tauri macOS bundles](https://tauri.app/distribute/macos-application-bundle/), [root resolution](gallery-lifecycle.md#root-selection-and-identity) |
| Artifact | A concrete distributable file or package whose version, platform and integrity can be identified | [Distribution contract](installation-and-distribution.md#distribution-contract) |
| Admission | Permission to begin one bounded preparation or native response; different resource classes have separate limits | [Loading policy](thumbnails-and-performance.md#adaptive-loading) |
| Frame callback gap | Elapsed monotonic time between visible animation callbacks; a responsiveness observation rather than proof of compositor frame presentation | [Rendering updates](https://html.spec.whatwg.org/multipage/webappapis.html#update-the-rendering), [measurement interpretation](thumbnails-and-performance.md#measurement-evidence-and-interpretation) |
| Private bytes | Process-private committed memory, reported separately from resident working-set pages | [PrivateMemorySize64](https://learn.microsoft.com/en-us/dotnet/api/system.diagnostics.process.privatememorysize64), [measurement interpretation](thumbnails-and-performance.md#measurement-evidence-and-interpretation) |
| Cache | Rebuildable derived data used to avoid repeating work; it is not the authoritative media collection or sole copy of preferences | [Cache contract](thumbnails-and-performance.md#cache-identity-and-freshness) |
| Codec | An encoding/decoding method for media; a file extension or container name alone does not establish that the active runtime can decode it | [HTML media resources](https://html.spec.whatwg.org/multipage/media.html), [capability reporting](browsing-and-playback.md#playback-and-capability-reporting) |
| Container | A media file structure that can hold encoded streams and related information; it is distinct from the codecs used by those streams | [HTML media resources](https://html.spec.whatwg.org/multipage/media.html), [playback](browsing-and-playback.md#playback-and-capability-reporting) |
| Decay | Expiration of machine-local remembered-location state after an explicitly chosen inactivity policy | [Remembered state](configuration-and-state.md#remembered-directory-state-and-decay) |
| Discovery operation | One explicitly requested opening or Refresh with its own ordering, cancellation and terminal result, independent of the lifetime of a gallery session | [Requested discovery](gallery-lifecycle.md#opening-and-discovery), [native interface](interfaces-and-contracts.md#native-and-frontend-operations) |
| Stale observation | A previous item not confirmed by the latest incomplete discovery; it remains distinguishable from a current observation and is not proof of deletion | [Maintaining a current view](gallery-lifecycle.md#maintaining-a-current-view) |
| Full installation | The installed product distribution providing declared dependencies, system integration and persistent user state | [Editions](overview.md#editions), [installation](installation-and-distribution.md#full-installation-and-lite-operation) |
| Gallery root | The selected directory against which a gallery session discovers and resolves its media | [Root selection](gallery-lifecycle.md#root-selection-and-identity) |
| Generation | A logical revision of a scan, item or source observation used to prevent obsolete asynchronous results from overwriting newer state | [Native interface](interfaces-and-contracts.md#native-and-frontend-operations) |
| Integrity | Agreement between bytes/state and an identified expected representation; a checksum does not independently establish the trustworthiness of its source | [Executable integrity](security-and-reliability.md#dependencies-and-executable-artifacts) |
| IPC | Inter-process communication; here, the host/interface boundary used to request native operations and deliver results/events | [Tauri process model](https://tauri.app/concept/process-model/), [native operations](interfaces-and-contracts.md#native-and-frontend-operations) |
| JSON | A text-based data interchange format supporting objects, arrays and scalar values; inspection must preserve meaningful source distinctions | [RFC 8259](https://www.rfc-editor.org/rfc/rfc8259.html), [metadata model](metadata-and-sidecars.md#metadata-model) |
| JSON Schema | A language for describing/validating JSON structures; a dialect must be declared when adopted for application-owned contracts | [JSON Schema specifications](https://json-schema.org/draft/2020-12), [data contracts](interfaces-and-contracts.md#data-contracts-and-versioning) |
| Lite | The lightweight application distribution intended for on-demand opening and sharing on supported hosts without installing Full | [Editions](overview.md#editions) |
| Masonry layout | Variable-height cards placed into the shortest available column while preserving a defined logical document and keyboard order | [Card layout](browsing-and-playback.md#cards-and-layout) |
| Lexical number | The original validated JSON number token, retained as text so exponent form, negative zero and large values survive native/frontend transport | [RFC8259 numbers](https://www.rfc-editor.org/rfc/rfc8259.html#section-6), [exact metadata](metadata-and-sidecars.md#inspection-and-field-inclusion) |
| Summary field address | A relative source role plus decoded object-key occurrence or positional array-index steps, used to select metadata without persisting native access grants | [Summary fields](metadata-and-sidecars.md#inspection-and-field-inclusion), [state resolution](configuration-and-state.md#resolution-and-persistence) |
| Metadata | Information about an item from file observations, media inspection or external documents, presented with its source | [Metadata and sidecars](metadata-and-sidecars.md#metadata-model) |
| Native host | The Rust/Tauri application layer that owns filesystem, job, state and platform capabilities behind the interface | [Tauri process model](https://tauri.app/concept/process-model/), [native core](architecture.md#native-host-and-gallery-core) |
| Next.js | The React framework selected to build the website and statically exported gallery interface | [Static export](https://nextjs.org/docs/app/guides/static-exports), [interface boundary](architecture.md#interface-build-and-runtime-data) |
| Normative requirement | A prescribed contract, distinguished from explanatory prose or an unresolved proposal by the specification's interpretation rules | [RFC 2119](https://www.rfc-editor.org/rfc/rfc2119.html), [RFC 8174](https://www.rfc-editor.org/rfc/rfc8174.html), [interpretation](index.md#how-to-interpret-requirements) |
| Pagination | Dividing the fully filtered and sorted collection into bounded pages; it limits mounted cards without limiting total collection size | [Collection presentation](browsing-and-playback.md#collection-presentation) |
| Preparation | Optional presentation and thumbnail work; 0.1.0 provides existing settings/jobs while guided acquisition of recipient launchers is deferred | [Preparation lifecycle](gallery-lifecycle.md#optional-preparation) |
| Provenance | The recorded origin, identity and versions of an artifact or metadata observation, allowing its context to be evaluated | [Data authority](architecture.md#data-flow-and-authority), [brand provenance](brand.md#provenance-and-updates) |
| Reconciliation | Comparing current directory contents with prior observations when opening or explicitly refreshing a gallery | [Current view](gallery-lifecycle.md#maintaining-a-current-view) |
| Relative path | A native filesystem path interpreted against a defined base such as the current gallery root, rather than requiring the sender's absolute filesystem location | [Rust native paths](https://doc.rust-lang.org/std/path/struct.Path.html), [root identity](gallery-lifecycle.md#root-selection-and-identity) |
| Runtime prerequisite | A platform facility required to execute a particular artifact; distinct from tools used to build it | [Build/runtime boundary](architecture.md#dependency-and-build-boundaries) |
| Rust | The native implementation language selected for the application; its ownership model manages memory through compiler-checked rules | [Rust ownership](https://doc.rust-lang.org/book/ch04-01-what-is-ownership.html), [architecture](architecture.md#native-host-and-gallery-core) |
| Semantic Versioning | Release numbering using major, minor and patch components with explicit compatibility meaning | [SemVer 2.0.0](https://semver.org/spec/v2.0.0.html), [release identity](verification-and-compatibility.md#compatibility-and-version-identity) |
| Sidecar | A separate nearby document associated with media through a declared matching/reference rule | [Sidecar association](metadata-and-sidecars.md#association-and-discovery) |
| Settings precedence | Ordered resolution of defaults, user choices, remembered choices, portable choices and explicit session intent, with a source for each field | [Resolution](configuration-and-state.md#resolution-and-persistence) |
| Portable presentation | Sparse deliberate view choices carried by the gallery-local settings.json independently of a sender profile or path | [Portable settings](configuration-and-state.md#portable-settings) |
| Inactivity expiry | Removal of convenience history at 90 days since successful opening or an explicit remembered save, without removing gallery data | [Activity and decay](configuration-and-state.md#remembered-directory-state-and-decay) |
| SQLite | An embedded transactional SQL database engine, bundled for remembered-location state rather than a mandatory external media catalog | [SQLite](https://sqlite.org/about.html), [remembered state](configuration-and-state.md#remembered-directory-state-and-decay) |
| Static export | Build-produced HTML/CSS/JavaScript assets that do not need a Next.js runtime server for the exported interface | [Next.js static exports](https://nextjs.org/docs/app/guides/static-exports), [interface build](architecture.md#interface-build-and-runtime-data) |
| Supported host | An OS/architecture/runtime combination explicitly supported by an artifact's release contract | [Distribution identity](installation-and-distribution.md#distribution-contract) |
| Tauri | The selected native application framework connecting Rust application capabilities to a webview interface | [Tauri architecture](https://tauri.app/concept/process-model/), [system context](architecture.md#system-context) |
| Thumbnail | A derived lower-cost visual representation used for browsing, not a required original or authoritative source | [Thumbnail contract](thumbnails-and-performance.md#optional-generation-lifecycle) |
| URI | A structured resource identifier; URI escaping and filesystem path interpretation are separate operations | [RFC 3986](https://www.rfc-editor.org/rfc/rfc3986.html), [media delivery](interfaces-and-contracts.md#media-delivery-and-item-references) |
| Virtualized rendering | Rendering a bounded useful portion of a larger logical collection, with additional work admitted as the view changes | [Adaptive loading](thumbnails-and-performance.md#adaptive-loading) |
| WCAG AA | An accessibility conformance level; relevant rendered behavior must be evaluated rather than inferred from a source declaration | [WCAG 2.2](https://www.w3.org/TR/WCAG22/), [interaction](browsing-and-playback.md#interaction-accessibility-and-feedback) |
| Webview | A native application's embedded web-content rendering surface, which has platform runtime dependencies without requiring a user-selected browser application | [Tauri process model](https://tauri.app/concept/process-model/), [dependency boundary](architecture.md#dependency-and-build-boundaries) |
| XDG locations | Linux user directory conventions separating configuration, persistent state and disposable caches | [XDG Base Directory Specification](https://specifications.freedesktop.org/basedir/latest/), [installed locations](configuration-and-state.md#installed-locations) |
| ABI | Application binary interface, including native calling/linking and library compatibility; a newer Linux build does not establish compatibility with an older glibc | [Rust platform support](https://doc.rust-lang.org/rustc/platform-support.html), [platform matrix](installation-and-distribution.md#initial-platform-and-dependency-matrix) |
| Startup acknowledgement | A bounded matching receipt that a detached child's main-window bridge and initial request are ready; distinct from discovery completion | [Process lifetime](interfaces-and-contracts.md#native-command-syntax-and-process-lifetime) |
| Native path encoding | Exact Windows UTF-16LE code-unit bytes or Unix filesystem bytes, separate from a display label | [Rust OsStr](https://doc.rust-lang.org/std/ffi/struct.OsStr.html), [machine results](interfaces-and-contracts.md#machine-results-and-exit-codes) |
| Proof archive | An identified exploratory payload with exact inventory and extracted native acceptance; it is not a final installer or published product release | [Package policy](installation-and-distribution.md#package-and-installation-policy) |
| Release candidate | An identified proposed product version with exact artifacts and qualification evidence; it does not itself establish public availability | [Release assembly](installation-and-distribution.md#verified-release-assembly-and-publication) |
| Canonical release record | The verified published record binding actual release/tag/assets, source/version, artifact hashes and documentation gates to the current downloads | [Release identity](installation-and-distribution.md#verified-release-assembly-and-publication) |
| Documentation gate | Matching complete retained-source, renderer, exported-output and check evidence required before product publication or canonical promotion | [Publication gates](website-and-documentation.md#release-snapshots-and-documentation-gates) |

## Maintaining terminology

Major releases require a rescan of the complete documentation for technical vocabulary. Update definitions, primary references and local usage links together. Retained versions must keep definitions consistent with their own contracts; a newer meaning must not silently replace an older release's terminology.
