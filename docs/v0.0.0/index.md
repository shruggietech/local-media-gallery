# Local Media Gallery documentation

v0.0.0 is a specification and maintainer-tooling baseline; application commands and installable packages do not exist yet.

Local Media Gallery is a lightweight, interactive gallery for browsing local images and videos. The planned application uses Rust, Tauri and a static Next.js interface on Windows, Linux and macOS. Full installation provides system integration and persistent user state, with dependencies handled through an appropriate platform installer. Lightweight Lite binaries support on-demand directory browsing and gallery sharing on supported hosts. Thumbnail preparation is optional. Storage details, supported-host prerequisites and exact distribution packages are being defined. The documentation website will use Next.js.

Read [brand integration](brand.md) for the upstream asset contract and [CONTRIBUTING.md](../../CONTRIBUTING.md) for local checks and development workflow. Once the documentation website exists, it will render the master changelog and published JSON contracts alongside the authoritative documentation.
