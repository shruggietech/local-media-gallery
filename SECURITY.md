# Security policy

## Reporting

Use a private contact route listed on the [ShruggieTech website](https://shruggie.tech/). Do not post credentials, private media or exploit details publicly. A project-specific private reporting route can be enabled after the GitHub repository is created.

Include the affected version or commit, a minimal reproduction, impact and relevant dependency versions. Remove credentials and private content. Maintainers coordinate fixes and disclosure; this project does not promise a response-time SLA.

## Supported versions

v0.0.0 is a local specification and maintainer-tooling baseline. No product binaries or packages exist yet. Security support for application releases will be documented when they exist.

## Data and dependencies

Access control, media handling, persistence and credential requirements will be specified with the product architecture. Maintainer tooling validates imported brand archives and records their origin, hashes and publication status. Passing repository checks does not establish application security or field behavior.
